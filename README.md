### (School Annual Operational Plan & Budget Allocation System)
พัฒนาสำหรับโรงเรียนระดับการศึกษาขั้นพื้นฐาน (สพป. / สพม. / สพฐ. กระทรวงศึกษาธิการ)

## 📌 จุดเด่นและวัตถุประสงค์
1. **สถาปัตยกรรม Node.js เต็มรูปแบบ (Node.js Full-Stack)**: รันด้วย Express + Vite + TypeScript บน Port 3000 สมบูรณ์แบบตามมาตรฐาน Google AI Studio พร้อม API สำหรับ AI และการจัดการข้อมูล
2. **จัดเก็บข้อมูลพื้นฐานโรงเรียนและข้อมูลนักเรียน** แยกตามระดับชั้น (อนุบาล 1 - ประถม 6) ชาย/หญิง และคำนวณยอดรวมอัตโนมัติ
3. **ประมาณการรายรับตามเกณฑ์ สพฐ.** (เงินอุดหนุนรายหัว, Top Up โรงเรียนคุณภาพ, หนังสือเรียน, เครื่องแบบ, อุปกรณ์, กิจกรรมพัฒนาผู้เรียน, ปัจจัยพื้นฐานนักเรียนยากจน กสศ., อาหารกลางวัน อปท., รายได้สถานศึกษา) ในรูปแบบคล้ายสเปรดชีต Excel
4. **จัดสรรงบประมาณตามฝ่าย/งาน** (วิชาการ, งบประมาณ, บุคคล, บริหารทั่วไป, งบกลาง) พร้อมระบบตรวจสอบผลรวม 100% อัตโนมัติ และระบบตัดแผนงบประมาณ
5. **จัดสรรงบกิจกรรมพัฒนาผู้เรียน 4 กิจกรรมหลัก** พร้อมระบบตรวจสอบ 100%
6. **ระบบผู้ช่วยเขียนโครงการด้วย AI**: ขับเคลื่อนด้วย Gemini 3.8 Flash ผ่าน Node.js Server หรือ Google Apps Script
7. **จัดทำโครงการตามแผนปฏิบัติการประจำปี** บันทึกหลักการ วัตถุประสงค์ ตัวชี้วัด วิธีดำเนินงาน และรายละเอียดค่าใช้จ่าย (จำนวน x ราคาต่อหน่วย = รวมเงิน)
8. **ระบบตรวจสอบและควบคุมงบประมาณ** ป้องกันการเบิกจ่ายเกินงบประมาณ (Over-budget Alert) คำนวณยอดคงเหลือแบบเรียลไทม์
9. **เชื่อมโยงยุทธศาสตร์ กลยุทธ์ เป้าประสงค์ ตัวชี้วัด** สู่แผนปฏิบัติการประจำปี
10. **Dashboard กราฟิกและสถิติด้วย Chart.js**
11. **ระบบรายงานและ Export** พิมพ์เอกสาร, ส่งออก Excel (.xlsx), Word (.doc), SQL (.sql) และ PDF (.pdf)
12. **ระบบสิทธิ์ผู้ใช้งาน (RBAC)**: Administrator, ผู้อำนวยการโรงเรียน, ครู/ผู้รับผิดชอบโครงการ

## 🛠️ สถาปัตยกรรมระบบ (Architecture & Runtime)

### 1. สภาพแวดล้อมหลัก: Node.js (Google AI Studio / Cloud Run / VPS)
- **Runtime**: Node.js v20+ / v22+
- **Framework**: Express.js + Vite (TypeScript)
- **Port**: 3000 (bind `0.0.0.0:3000`)
- **Build Tool**: `vite build` + `esbuild server.ts --bundle --platform=node --format=cjs --outfile=dist/server.cjs`
- **Commands**:
  - `npm run dev`: เริ่มต้นรันเซิร์ฟเวอร์โหมดพัฒนาด้วย `tsx server.ts`
  - `npm run build`: คอมไพล์โปรเจกต์ React และ Express Server
  - `npm start`: รันเซิร์ฟเวอร์โปรดักชันด้วย `node dist/server.cjs`

### 2. การ Deploy เป็น Web App (cPanel / VPS / Cloud Run)
- **cPanel (Setup Node.js App)**:
  - Application startup file: `app.js`
  - Run `npm run build` ใน Terminal
  - ระบบเชื่อมต่อฐานข้อมูลอัตโนมัติผ่าน `config/db_config.json` หรือผ่านหน้า Super Admin โดยไม่ต้องใช้ไฟล์ `.env`
- **Docker / Cloud Run**:
  - รันผ่านพอร์ต 3000 ด้วย `node dist/server.cjs`

## 🚀 คู่มือการติดตั้งบน cPanel (Setup Node.js App)

### ขั้นตอนที่ 1: อัปโหลด Source Code
1. เข้าสู่ระบบ **cPanel** ของผู้ให้บริการโฮสติ้ง
2. ไปที่เมนู **Setup Node.js App** แล้วกด **Create Application**
3. ระบุการตั้งค่า:
   - **Node.js version**: 20.x หรือ 18.x
   - **Application mode**: Production
   - **Application startup file**: `app.js`
   - **Application URL**: โดเมนที่ต้องการใช้งาน

### ขั้นตอนที่ 2: นำเข้าฐานข้อมูล MySQL (Import Database)
1. ไปที่เมนู **MySQL Databases** ใน cPanel สร้าง Database และ User
2. เข้าเมนู **phpMyAdmin** เลือกฐานข้อมูลที่สร้าง
3. คลิกแท็บ **Import** แล้วนำเข้าไฟล์ `database/schema.sql` และ `database/seed.sql`

### ขั้นตอนที่ 3: ตั้งค่าการเชื่อมต่อฐานข้อมูล
- เข้าใช้งานระบบหน้าเว็บ แล้วไปที่เมนู **Super Admin (ศูนย์ควบคุมฐานข้อมูล)**

- ระบบจะบันทึกคอนฟิกลง `config/db_config.json` ให้โดยอัตโนมัติ โดยไม่จำเป็นต้องใช้ไฟล์ `.env` หมดกังวลเรื่องไฟล์คอนฟิกถูกเขียนทับเวลาอัปโหลดโค้ดผ่าน SFTP

## 📊 สูตรการคำนวณสำคัญในระบบ

1. **จำนวนนักเรียนรวม**:
   $$\text{รวม} = \text{นักเรียนชาย} + \text{นักเรียนหญิง}$$
   $$\text{นักเรียนทั้งหมด} = \sum (\text{รวมแต่ละชั้นปี})$$

2. **ประมาณการรายรับแต่ละรายการ**:
   $$\text{จำนวนเงิน} = \text{จำนวนผู้มีสิทธิ์} \times \text{อัตราต่อคน}$$

3. **จัดสรรงบประมาณตามฝ่ายงาน**:
   $$\text{งบประมาณที่จัดสรร} = \text{งบประมาณรวม} \times \frac{\text{เปอร์เซ็นต์}}{100}$$
   *(โดยที่ $\sum \text{เปอร์เซ็นต์} = 100\%$)*

4. **งบประมาณโครงการ**:
   $$\text{ค่าใช้จ่ายแต่ละรายการ} = \text{จำนวน} \times \text{ราคาต่อหน่วย}$$
   $$\text{งบประมาณรวมโครงการ} = \sum (\text{ค่าใช้จ่ายทุกรายการ})$$

5. **งบประมาณคงเหลือ**:
   $$\text{งบประมาณคงเหลือ} = \text{งบประมาณที่ได้รับ} - \text{งบประมาณที่ใช้ไปจริง}$$

## 🛡️ มาตรการความปลอดภัย
- ใช้งาน **PDO Prepared Statements** ครบถ้วน ป้องกัน SQL Injection 100%
- เข้ารหัสผ่านด้วย **bcrypt (password_hash)**
- ตรวจสอบสิทธิ์ **Role-Based Access Control (RBAC)** ในทุกส่วนงาน
- ป้องกัน Cross-Site Scripting (XSS) ด้วย `htmlspecialchars()`
- ป้องกัน CSRF Attacks ด้วยการตรวจสอบ Anti-CSRF Token
